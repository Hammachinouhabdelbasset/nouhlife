# Templates

| File | Use |
|---|---|
| `lab-report.tex` | Lab report (cover page, objectives, theory, procedure, results tables, waveforms, discussion, conclusion). Copy into `lab/labNN-<topic>/report.tex`. |
| `td-solution.tex` | Solution of a TD series (exercise / solution boxes). Copy into `td/seriesNN/solution.tex`. |

Full worked example of a lab report: [`../power-electronics/lab/lab01-single-phase-rectifier/report.tex`](../power-electronics/lab/lab01-single-phase-rectifier/report.tex)
(circuitikz circuits, pgfplots oscilloscope-style waveforms, tables that compute F.F./R.F./η automatically).

Compile with `pdflatex` (twice, for the table of contents) or on Overleaf.

## Syllabus checklist

- [ ] Process control elements, block diagrams, setpoint, error
- [ ] Signal conditioning: bridge circuits, op-amp circuits (follower, differential, integrator, summer)
- [ ] Thermal transducers: thermistor, RTD, thermocouple
- [ ] Mechanical transducers: displacement, strain gauge; pressure and flow sensors
- [ ] Optical transducers
- [ ] Controller principles: P, I, D, PI, PD, PID, Ziegler-Nichols tuning, op-amp controllers
- [ ] Final control: pneumatic and hydraulic actuators, final control elements

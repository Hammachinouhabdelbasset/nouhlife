## Syllabus checklist

- [ ] Review of digital design with VHDL examples
- [ ] Data representation: integers, reals, characters
- [ ] Basic architecture: memory / I/O maps, CPU elements, interrupts
- [ ] Micro-architecture: MIPS single-cycle, multi-cycle, pipelined
- [ ] Assembly language: R / I / J formats, addressing modes, assembler, compiler
- [ ] Memory organisation: interleaving, cache, mass storage, virtual memory
- [ ] I/O organisation: parallel / serial interfaces, protocols
- [ ] Microprocessor architectures (8/16/32/64-bit)
- [ ] Large systems: parallel, systolic, neural

## How to study it

- Review within 24 h of each lecture.
- Practise MIPS assembly and instruction encoding by hand.
- Draw single-cycle, multi-cycle and pipelined datapaths from memory.
- Cache and memory-hierarchy calculations.
